# FoodSaver Code of Conduct

## Our Commitment

FoodSaver is an open-source project focused on reducing food waste. We want everyone involved in the project to feel welcome and respected, whether they contribute code, documentation, design, testing, or ideas.

## Expected Behavior

All contributors are expected to:

- Communicate politely and respectfully.
- Give constructive feedback about work, not personal criticism.
- Respect different backgrounds, experiences, and opinions.
- Help new contributors understand the project.
- Keep discussions focused on improving FoodSaver.
- Respect other people's privacy and do not post personal information without permission.

## Unacceptable Behavior

The following behavior is not accepted:

- Harassment, bullying, discrimination, or personal insults.
- Offensive or threatening comments.
- Sharing another person's private information without consent.
- Spamming discussions, issues, or pull requests.
- Deliberately disrupting team collaboration.

## Where These Rules Apply

These rules apply to FoodSaver's GitHub repository, issues, pull requests, code reviews, and project-related discussions.

## Reporting Problems

If you experience or notice a Code of Conduct issue, contact a FoodSaver project maintainer privately using a team-approved communication channel. Do not publish private reports or sensitive information in a public issue.

Maintainers will review reports, keep details limited to the people who need to know, and decide on appropriate actions. These may include a warning, removal of inappropriate content, or limiting participation.

## Our Shared Goal

We welcome contributions that make FoodSaver easier to use, safer, and more useful for reducing food waste.
